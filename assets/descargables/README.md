# Descargables

Acá van los PDF de la pestaña Descargables (el cuadernillo y las 6 fichas del kit). El cuadernillo todavía no está: mientras su `file` esté vacío, la página muestra "Próximamente".

Para activar el botón "Descargar PDF" de cada uno, poné el archivo en esta carpeta y escribí su nombre en el campo `file` del arreglo `DESCARGABLES` en `js/app.js` (por ejemplo `file: "cuadernillo.pdf"`).

Las imágenes de vista previa (tapa y páginas) van en `assets/img/descargables/` y se listan en el campo `pages`. Mientras no haya imágenes, la página dibuja una tapa con el número y el nombre.
